# Project Overview
This project is an Azure VM health monitoring solution created with PowerShell. It should help admins monitor virtual machines and identify VMs that may require attention.
# Features
- Retrieves Azure VM information
- Displays VM name, resource group, and power state
- Uses variables to store VM information
- Uses loops to process multiple VMs
- Uses conditional logic to evaluate VM status
- Identifies healthy VMs
- Identifies VMs that need attention
- Provides organized VM health results
# Commands Used
Get-AzVM
- Write-Host
- Select-Object
- foreach
- if
